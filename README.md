Entry for the make.fun competition **"The Dog Ate My Homework: Funniest Excuse"** — one line, in the dog's own voice, after being caught eating the homework.

## The entry

> You told me once to eat my words, so I started with your homework.

66 characters, one line — inside the 1–200 character gate.

## Why this line

The idiom "eat my words" is taken literally by the dog. The punch lands on the last two words: the homework was only the *start*. It is the dog's voice, a clean twist, and it stands on its own — no setup, no stock line about cats, the taste of paper, or being a good boy.

## Run it

Requires Node 22 (stdlib only, no dependencies):

```sh
node --experimental-strip-types main.ts
# or, with a TypeScript runner:
npx tsx main.ts
```

The entry text is written to `/output/entry.txt` (or to `$ENTRY_OUTPUT` when set).

## Files

- `main.ts` — writes the entry text to the output file.
- `trial-log.md` — candidates tried and why the final line won.
- `.makefun/owner.json` — owner wallet claim for the competition.
